Add **programme reminders** and **recording-storage preflight** on top of released v1.150.48, after merged #100. The VOD library is already in the base and is not resubmitted.

Future EPG rows in the channel guide, What's On Now and programme search offer Set Reminder with 0–120 minute lead time. The keyboard-operated manager supports review, lead-time editing, confirmed Delete/Clear All and Refresh. Notifications default to Close, wait behind native/custom modal dialogs, and open a uniquely resolved current channel only on explicit consent. Pending reminders warn on normal exit. The bounded atomic store excludes media URLs/credentials, preserves earlier data on failed writes and does not overwrite malformed files. Durable ready/acknowledged states support restart without pretending to guarantee exactly-once delivery across a crash. Ended programmes expire; the feature does not wake the computer or automatically follow later EPG changes.

RecordingManager validates actual destination writeability and current free bytes before acquiring the local-buffer recording lease, reserving output paths or launching FFmpeg. This central path covers manual/scheduled captures and recorder-backed catch-up downloads. A configurable 0–65536 MiB pre-start floor defaults to 256 MiB; unknown capacity fails closed. Starts are serialized through validation/registration, and a failed scheduled start reaches the existing failed state without a phantom recording ID. The manual storage-check command runs on a worker. No user files are deleted. This is not a full-size reservation, bitrate/duration prediction or continuous free-space monitor; concurrent writers can consume space afterwards.
